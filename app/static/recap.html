About the recap

Each week is measured from the same recorded laps as Rivalry and Stats: a lap counts as valid when it has no rewind and no contact and is not excluded. A personal best is a driver’s fastest valid time on a route and class that week, when it beat everything they had recorded there before. Records are counted on routes where two or more drivers have a valid time.

The written column is optional. An AI writes it from that week’s measurements only, and every number it uses is checked against them; a column that fails the check is not shown. It is written automatically about an hour after a week ends, once, and can be written by hand for any finished week.
